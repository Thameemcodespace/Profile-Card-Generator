# 💜 Profile Card Generator

A modern and professional Profile Card Generator built using **Python, Flask, HTML, CSS, and JavaScript**.

Create beautiful personalized profile cards by entering your details, uploading your profile picture, previewing your design, and downloading your card.

## ✨ Features

- 📝 Enter personal and professional details.
- 📸 Upload your profile picture.
- 👀 Preview your profile card instantly.
- 🎨 Modern dark theme with violet accents.
- 💾 Download your generated profile card as an image.
- 📱 User-friendly interface.

## 🛠️ Technologies Used

- Python
- Flask
- HTML5
- CSS3
- JavaScript
